# E-Commerce Full Stack Application

Professional e-commerce application with React frontend and Node.js backend.

## Features

- JWT Authentication with validation
- Product listing with search functionality
- Shopping cart with Redux state management
- Order placement system
- Responsive design

## Setup Instructions

### Backend Setup
```bash
cd Backend
npm install
npm start
```

### Frontend Setup
```bash
cd ecomm
npm install
npm run dev
```
